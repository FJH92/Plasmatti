This folder contains the two synthetic demonstration sessions distributed with Plasmatti.

The data are INVENTED for demonstration; no value comes from a real sample or laboratory.
They are written in the layout of PerkinElmer Optima ICP-OES exports.

Demo session (liquid)  - ten water samples, with blanks and 1 and 20 mg/L standards
                         measured before and after the samples (the session used in the article).
Demo session (solid)   - the same measurements treated as digests of solid samples,
                         with a dissolution file giving the sample masses and final volume.

Each folder has an ABOUT_DEMO.txt that explains what to look for.

The same sessions are also built into src/plasmatti.py and can be opened directly from the
program, so this folder is not needed to run the demos.
